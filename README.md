# Elliot Gong — Portfolio Website

**Live site:** [theelliotgong.com](https://theelliotgong.com)

This is my personal portfolio. It brings together my work in software engineering, full-stack web development, AI, IT and automation, game and level design, UX/UI design, and 3D art. Each project links out to its live demo, repository, video, or art page where one exists.

## What's on the site

- **Hero:** a short introduction, my headshot, and links to my LinkedIn, GitHub, ArtStation, Sketchfab, and Figma profiles.
- **Projects:** a gallery grouped into six categories. Each category also has its own page at `/projects/<category>`:
  - AI and Machine Learning
  - Web Applications
  - IT and Automation
  - Games and Levels
  - UX and UI
  - 3D Art
- **Experience:** my work history.
- **Skills:** my technical and creative skills, grouped by area.
- **Education:** my degrees.
- **Certifications:** my certificates, each with a link to verify it.
- **Contact:** a contact form (sent through FormSubmit) and a footer.

## Tech stack

- [React 19](https://react.dev/) with [React Router](https://reactrouter.com/) for the home page and the project category pages
- [Vite](https://vite.dev/) for local development and production builds
- [Bulma](https://bulma.io/) for styling and the responsive layout
- GitHub Actions and GitHub Pages for deployment, served on a custom domain
